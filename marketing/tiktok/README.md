# Ролики для TikTok

Три вертикальных ролика (1080×1920, 16–18 с) для поиска тестировщиков:

| Файл | Идея |
|---|---|
| `spisano-a-number.mp4` | «Сколько ты тратишь на подписки?» — счётчик до 13 833 ₽ в месяц |
| `spisano-b-trial.mp4` | «Пробный период закончился» — Subly напомнил бы за день |
| `spisano-c-solo.mp4` | «Я сделал приложение. Один.» — нужны 12 тестировщиков |
| `spisano-d-rebrand.mp4` | «Назвал приложение Subly → оказалось, их уже 7» → новое имя «Списано» (голос + музыка, дроп и слово «Списано» на появлении нового имени) |

Подписи, хештеги и закреплённый комментарий: `tiktok-captions.md`.

## Звук

- **Голос:** Gemini TTS, голос `Achird` (ролики А и Б — модель `gemini-3.8-flash-tts`, В — `gemini-2.5-flash-preview-tts`, слово «Один.» — `gemini-3.8-flash-lite-tts`: у бесплатного ключа лимит 10 фраз в день на модель). Тексты и тайминги — словарь `VOICE` в `build.py`, готовые фразы — `shared/voice/` (повторно не генерируются).
  Чтобы перегенерировать: положите ключ Google AI Studio в файл и запустите `GEMINI_KEY_FILE=путь/к/файлу python3 build.py`. Ключ в репозиторий не кладите.
- **Музыка:** инструментальные треки из библиотеки HeyGen (`shared/music/`): А — электроника 128 BPM с дропом на «166 001 ₽ в год», Б — лоу-фай 80 BPM, В — инди-электроника 128 BPM, слова «Один. Без рекламы…» стоят на сильных долях.
- Обработка голоса: обрезка тишины, срез ниже 80 Гц, мягкий de-esser, плавные края, одно статичное усиление на фразу (без динамической нормализации).
- Музыке срезан суббас ниже 120 Гц и приглушена область 200 Гц: динамики телефонов на таком басе дребезжат.
- Мастер после рендера: только статичное усиление до −14,5 LUFS, но не выше пика −1 dBFS, без лимитера:
  `ffmpeg -i in.mp4 -c:v copy -af "volume=<+N>dB" -c:a aac -b:a 192k out.mp4`.

Чтобы поменять голос: скачайте другую модель Piper (`ru_RU-denis-medium`, `ru_RU-ruslan-medium`), укажите её в `VOICE_MODEL` и запустите `python3 build.py` заново.

## Пересобрать

Ролики сделаны в [HyperFrames](https://hyperframes.heygen.com) (HTML → видео).
`build.py` генерирует три проекта из общих материалов в `shared/` (настоящие экраны приложения, шрифты, иконка):

```bash
python3 build.py          # создаёт a-number/, b-trial/, c-solo/
cd a-number && npx hyperframes render
```

Перед сборкой поправьте пути в начале `build.py` (`/home/user/subly/fonts/fonts.css`) под свою папку.

|---|---|---|
| 1 | `week/subly-w1-forgot.mp4` | 5 подписок, которые ты забыл отменить |
| 2 | `week/subly-w2-coffee.mp4` | 399 ₽ в месяц — это мало? (399 × 12 × 10) |
| 3 | `week/subly-w3-family.mp4` | Семейная подписка: твоя доля |
| 4 | `week/subly-w4-bills.mp4` | ЖКХ и аренда, кнопка «Оплачено» |

Подписи: `week/captions-week.md`. Сборка: `build_week.py` (переиспользует `build.py`), экраны Subly — `shared-subly/assets/` (шрифты берутся из `shared/assets/fonts`), треки — `music/`.

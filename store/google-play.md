# Google Play: пошаговая публикация «Списано»

## 0. Один раз: ключ загрузки в GitHub

Ключ загрузки (upload key) хранится **только у вас** и в секретах GitHub, в репозитории его нет.
Откройте https://github.com/howknowme/Spisano/settings/secrets/actions → **New repository secret** и добавьте 4 секрета
(значения в файле `SECRETS-README.txt`, который вам прислали отдельно):

| Секрет | Значение |
|---|---|
| `SUBLY_UPLOAD_KEYSTORE_B64` | содержимое `keystore-base64.txt` |
| `SUBLY_UPLOAD_KEYSTORE_PASSWORD` | пароль |
| `SUBLY_UPLOAD_KEY_ALIAS` | `upload` |
| `SUBLY_UPLOAD_KEY_PASSWORD` | пароль |

Затем: **Actions → Build Android APK → Run workflow**. В новом релизе появится файл **`subly-google-play.aab`**: его и загружают в Google Play.

## 1. Аккаунт разработчика

1. https://play.google.com/console/signup → **Личный аккаунт** (Personal).
2. Подтвердите личность (паспорт или ID-карта), телефон, оплатите **25 $**.
3. **Имя разработчика**, которое увидят пользователи, можно указать любое (например, Howknowme).

## 2. Создать приложение

**Все приложения → Создать приложение**
- Название: `Списано: учёт подписок и платежей`
- Язык по умолчанию: **Русский – ru-RU**
- Тип: **Приложение**, **Бесплатное**
- Поставьте галочки с согласием на правила.

## 5. Закрытое тестирование (обязательно для новых личных аккаунтов)

Правило Google: **12+ тестировщиков, подписанных 14 дней подряд**, только потом можно запросить публикацию для всех.

1. **Тестирование → Закрытое тестирование → Создать трек** (или использовать «Alpha»).
2. **Тестировщики → Создать список адресов** → вставьте Gmail-адреса тестировщиков (минимум 12, лучше 15–20 с запасом: кто-то отпишется).
3. **Создать выпуск** → загрузите `subly-google-play.aab`.
   При первой загрузке выберите **«Использовать ключ, созданный Google»** (Google Play App Signing).
4. Название выпуска: `1.2.N`, примечание: «Первая версия для тестирования».
5. **Проверить выпуск → Начать развёртывание**.
6. Скопируйте **ссылку для участия** (opt-in link) и отправьте её тестировщикам вместе с текстом из `testers.md`.
7. Через **14 дней**: **Панель управления → Запросить доступ к рабочей версии**. Google задаст вопросы о тестировании. Отвечайте честно: сколько людей тестировали, какие отзывы получили, что исправили.

## 6. Обновления

При каждом изменении приложения в `main` GitHub собирает новый `subly-google-play.aab` (номер версии растёт сам).
Скачайте его из Releases → в Play Console **Создать выпуск** → загрузите.

## Полезно знать

- Сайт и APK из Releases подписаны другим ключом, чем версия из Google Play. Поверх друг друга они не ставятся. Перед переходом с APK на версию из Google Play сделайте резервную копию: **Настройки → Скачать копию**, потом **Загрузить из файла**.
- Приложение нацелено на Android 16 (API 36), как требует Google Play с 31 августа 2026.
- Разрешения: уведомления, запуск после перезагрузки (чтобы напоминания не пропадали), интернет (курсы валют). Особых разрешений вроде точных будильников, SMS или геолокации нет, поэтому дополнительные декларации не нужны.

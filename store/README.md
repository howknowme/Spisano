# Публикация Subly в магазинах

Всё для карточки приложения лежит в этой папке.

| Файл | Что это |
|---|---|
| `texts-ru.md` | Название, краткое и полное описание, «Что нового», категория, ключевые слова |
| `texts-en.md` | То же на английском (для Google Play) |
| `icon-512.png` | Иконка 512×512 |
| `feature-1024x500.png` | Баннер 1024×500 (обязателен в Google Play) |
| `screenshots/*.png` | 7 скриншотов 1080×1920 |

Политика конфиденциальности: https://howknowme.github.io/subly/privacy.html

APK для загрузки: https://github.com/howknowme/subly/releases/latest/download/subly.apk

## RuStore: по шагам

1. Откройте [rustore.ru/developer](https://www.rustore.ru/developer) и войдите через VK ID.
2. Создайте аккаунт разработчика с типом «Физическое лицо» и пройдите проверку.
3. «Создать приложение» → загрузите `subly.apk`. Имя пакета: `io.github.howknowme.subly`.
4. Если RuStore попросит подтвердить имя пакета, он выдаст файл или код. Передайте его разработчику: его нужно встроить в приложение и пересобрать APK.
5. Заполните карточку:
   - **Название, краткое и полное описание, «Что нового»**: из `texts-ru.md`.
   - **Иконка**: `icon-512.png`.
   - **Скриншоты**: все файлы из `screenshots/` по порядку.
   - **Категория**: Финансы. **Возраст**: 0+.
   - **Политика конфиденциальности**: ссылка выше.
   - **Контактный email**: ваш адрес для связи с пользователями (будет виден в карточке).
6. Отправьте на модерацию.

Обновления: GitHub Actions собирает новый APK при каждом изменении приложения в `main`. Скачайте его из Releases и загрузите в RuStore как новую версию. Номер версии растёт сам.

## Пересоздать картинки

```bash
npm run build
python3 -m http.server 8767 -d www &
node scripts/store-assets.cjs
```
